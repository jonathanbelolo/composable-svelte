# Composable Svelte starter

Copy this directory out of the installed package into your application directory.
For example, from a directory where core is installed:

```sh
cp -R node_modules/@composable-svelte/core/consumer ../my-app
cd ../my-app
npm install
npm run check
npm test
npm run build
npm run test:ssr
npx playwright install chromium
npm run test:browser
npm run dev
```

Use Node 20.19+ or 22.12+. Commit the lockfile generated by your first install.
The starter uses public npm exports, Tailwind 4, per-component stores and injected
effects. Tests cover the reducer's emitted action, SSR, browser updates and theme.
See the installed core `docs/consumer.md` for architecture and integration guidance.
Satellite README examples are added by the library's release gate, not required
for this minimal application. Configure your own API dependencies before adding
backend-driven features.
