# Document dismissal ownership

Modal, Sheet, Drawer, Alert and Popover primitives share the framework's document dismissal coordinator. Sidebar and NavigationStack provide lower-priority Escape fallbacks. The registry owns browser listeners and layer metadata, never business state. Dismissal still calls the existing scoped store or navigation callback; this change does not add a managed business veto API to legacy stores.

One Escape event requests dismissal from one eligible layer. Visible legacy overlays retain their layer during entrance and exit; transient interaction unreadiness vetoes their callback rather than exposing a lower modal. Hiding the retained view releases that participation. This is the legacy retained-view policy, not a managed inert-exit policy. A disabled Escape option shields lower layers. A callback which keeps its feature open does not cause fallback dismissal. Child handlers can preventDefault before the event reaches the document. Repeated and composing Escape events are ignored. The coordinator consumes a selected event before calling the feature.

Outside-pointer handling distinguishes two policies. The public bare clickOutside action retains its enabled=false behavior: that layer is skipped, allowing the next participating layer to receive the gesture. The adapted Modal, Sheet, Drawer, Alert and Popover primitives do not use that skip for disableClickOutside: a visible primitive stays pointer-eligible and owns the gesture, and its callback rejects the request. A disabled outside-pointer option therefore shields lower layers, including the logical parent of a portaled child, whether the pointer lands outside both or inside the child; like a disabled Escape option, rejection never falls through. Right and middle buttons do not dismiss. Containment is captured synchronously through the composed event path; the callback is deferred to preserve click behavior. Removal, enrollment of another layer, or replacement of the registered primitive's store invalidates a pending gesture. A prevented pointer event does not dismiss. Destroying an owner cancels its pending callbacks; releasing the final layer removes both document listeners.

Ownership follows the rendered node's ownerDocument. Portal string selectors resolve in that node's document; explicit Element targets may intentionally select another document. Open-shadow composed paths are supported. A document event cannot reveal hidden closed-shadow internal paths; register the shadow host as the boundary when those internals must be treated as one region.

This guarantee covers the adapted primitives and clickOutside participation. Select, third-party and other unadapted keyboard handlers are not yet covered by a complete mixed-layer guarantee. Private layer registration is not a public extension API. Framework focus restoration, trapping, scroll locks and managed presentation binding have separate qualification; these changes alone do not establish those guarantees. Server rendering enrolls no browser resources.
