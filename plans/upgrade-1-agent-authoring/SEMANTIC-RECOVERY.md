# Semantic recovery: bounded components

The large no-tools Fable implementation produced no code after two output-limit resumptions. The coordinator is taking implementation ownership and splitting the work. This changes task granularity, not detector coverage or acceptance standards. No incomplete checker may certify a consumer.

## Shared frontend interface (implementation target)

`parseSemanticModules({projectRoot, graph})` in `semantic-parse.mjs` returns `{modules, errors}`. It reads only the already-approved local graph modules. Each module has `{path, text, kind, units, scopes, markers, span(start,end)}`. `span` maps original UTF-16 offsets to the established start/end offset/line/column object. Errors use `{code:'unsupported-construct'|'parse-error'|'incomplete-graph', construct?, path, span, message}` and are sorted.

A scope is an object `{id, parent, bindings:Map}`; IDs deterministic within a module. Parser creates module, Svelte instance and template scopes only. Bindings initially empty. A unit is `{kind:'module'|'view'|'template'|'binding', sourceFile, base, scope}` where sourceFile is a TypeScript AST (setParentNodes true), and original offsets equal AST offsets + base. Synthetic parentheses/declaration prefixes are excluded from reported node spans by clamping to the original expression span. Unit also has `start,end` original boundaries. A unit of kind binding is a synthetic variable declaration solely introducing snippet/each/await/let bindings in its supplied scope; initializers are not semantic execution. Plain TS/JS files have a single module unit, preserving syntax and positions. The script language must be respected.

Svelte uses the real modern parser. Module script gets module scope; instance script gets child instance scope; all markup is in instance scope or descendant template scope. Script bodies are extracted using parser spans/attributes, not a regex. Template expressions become separate TS expression units using a parenthesized original source slice. Each/snippet/await bindings get explicit scopes; sibling fragments cannot share branch-local bindings. A snippet declaration is visible throughout its containing fragment; its parameters are visible only in its body. Nested expressions must not be visited twice. Markers preserve parsed node objects/spans and relevant scopes for component attributes, snippet declarations, bind:this, use/attach, and event/lifecycle bindings; these supply provenance later, not automatic exemptions. Exact marker shape is documented by the parser implementation. Unknown template forms produce actionable errors, not silently ignored content. This layer performs no taint or qualification.

`buildSymbols({modules})` in `symbols.mjs` augments scopes and returns `{errors, scopeOf(node), bindingOf(identifier), bindings, functions, imports, exports}`. It consumes the units above, no disk access. A binding has `{id,name,scope,declarations:[],initializers:[],assignments:[]}` with initializer/assignment AST nodes and their unit retained. Resolve lexical shadowing with proper block/function/parameter/catch/class scopes; var belongs to function/module scope. Binding patterns introduce leaf names with a property path descriptor, retaining default expressions/rest markers for later analysis. Scope mappings cover every AST node. Identifier lookup returns null for a free identifier; imported symbols remain bindings with import metadata rather than pretending to be globals.

Functions have `{node,unit,scope,parameters,body}`; include arrows, declarations, expressions, methods, constructors, getters/setters. `imports` records `{binding,specifier,imported:'default'|'*'|name,typeOnly,unit,node}`. `exports` records named/default/local/star/reexport information without resolving cross-module origins yet. Unsupported value namespaces, with, arguments use, unknown binding/declaration forms produce errors. Classes retain class-local bindings and method/field ASTs; do not discard bodies. Tests must demonstrate lexical shadowing, declarations after references, destructuring, default/rest parameters, catch/loops, method bodies, module versus instance scope, and template-binding parent scopes. Neither layer can clear taint, exempt wiring, activate a rule, or produce a successful qualification result.

The coordinator integrates import origin resolution, finite taint propagation, execution zones and five evaluators only after these components pass tests. Shallow-copy descendant aliasing and eager service-factory I/O remain required controls from CHECKER-DECISIONS.md. Published snippet compatibility remains an acceptance gate, not a reason to silently skip unsupported analysis.
